# Provenance of the Rust code

This file records where every file under `rust/` came from and which libraries
replaced components of the legacy program (STEP3-PLAN.md, section 3).

**No file in rust/ may have origin 'derived'. Adding one would make the whole app
GPL-2.0 and conflict with its Apache-2.0 dependencies.**

## Origins

| Origin | Meaning | SPDX licence |
|--------|---------|--------------|
| `new` | Written from scratch on the clean side; no legacy code used | `LicenseRef-NewCode-TBD` (later the licence chosen in decision L3) |
| `derived` | Translated from or based on legacy code | Not permitted in `rust/` (see the note above) |

## Dependencies with no MIT option

alone. They are allowed by owner decision L1b (16 Nov. 2026), which holds only
while the note at the top of this file holds.

| Crate | Version | Declared licence | Brought in by | In the shipped program |

| `glutin` | 0.32.3 | Apache-2.0 | `eframe` (OpenGL backend) | Yes |
| `glutin_egl_sys` | 0.7.1 | Apache-2.0 | `glutin` | Yes |
| `glutin_wgl_sys` | 0.6.1 | Apache-2.0 | `glutin` | Yes |
